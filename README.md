# Makoski Studio — site inicial

Arquivos:
- index.html
- styles.css
- script.js
- assets/logo.jpg
- assets/logo-web.jpg

## Como usar
1. Mantenha a estrutura de pastas.
2. Abra `index.html` no navegador.
3. No `script.js`, troque `WHATSAPP_NUMBER` pelo número real do Studio, com código do país e DDD, somente números.

Exemplo:
`5544999999999`

O formulário não envia dados para um banco. Ele monta uma mensagem e abre o WhatsApp.

## Observação sobre a identidade
A logo enviada pelo cliente foi incorporada como imagem raster. Para produção profissional, o ideal é ter uma versão vetorial (SVG/AI/EPS) da marca, preservando os traços originais.
